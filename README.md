# Last Signal

Showcase and download page for **Last Signal**, a night-driving game for Mac and Windows (Pripyat, 26 April 1986), by Glenn Svendsen.
Live at https://glennsvendsen.github.io/last-signal/ once published (GitHub Pages, deploys on push to `main`).

Static site, no build step. Preview: `python3 -m http.server 8000`, then open http://localhost:8000.
See `CLAUDE.md` for the design rules and how the media is delivered.
