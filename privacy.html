Last Signal · Privacy

Privacy

Last updated 19 November 2026

The short version

Last Signal does not collect, store or share any personal data. There are no accounts, no ads, no tracking and no in-app purchases. The game does not need an internet connection.

The game (iPhone, Mac, Windows)

  • No data leaves your device. The game makes no network requests and contains no analytics, advertising or crash-reporting services.
  • Saved on your device only: your settings (volume, controls, camera, graphics, subtitles), your best runs and log, and your garage progress. Deleting the game deletes them.
  • Motion sensor: if you choose tilt steering on iPhone, the game reads the phone's tilt to steer. It is used in the moment and never stored or sent anywhere.
  • No permissions for camera, microphone, location, contacts or photos are requested.

This website

  • Hosting: the site is hosted on GitHub Pages. GitHub may log your IP address for security, as described in the GitHub Privacy Statement.
  • Visit counts: the site uses Umami, a cookie-free analytics service, to count page views and how the page is used: clicks on buttons such as Download, how far into the trailer people watch, which gallery images are opened and which sections are scrolled to. It does not use cookies, does not identify you and does not follow you to other sites.
  • Download count: your browser asks GitHub's public API how many times the game has been downloaded. Downloads themselves are served from GitHub.
  • Fonts are served from this site, not from a third party.
  • Feedback is sent through GitHub issues, which are public. Do not include anything you want to keep private.

Children

The game collects no data from anyone, including children.

Changes

If this changes, for example if a future version adds online features, this page will be updated before that version is released, and the date above will change.
